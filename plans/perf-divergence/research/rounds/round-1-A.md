## hypotheses to test
All items below are HYPOTHESES, not findings; none has been run.
- H1 (LayerNorm, high prior): native x64 uses the AVX2+FMA3 centered two-pass/fp64-mean kernel (A-4/A-5) while WASM uses scalar float Welford (A-3), so the 26 LayerNormalization outputs differ by low-order bits per row, more when |mean| >> std. Test: extract one LN node with real activations as a single-node model; compare native, WASM and a float64 numpy reference; see which is closer and whether the gap matches the model-level gap.
